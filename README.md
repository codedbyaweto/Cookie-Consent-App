# Cookie Consent Pop-Up App

A fun, interactive cookie consent application built with HTML, CSS, and JavaScript.  
This project humorously mimics typical cookie consent pop-ups but adds a playful and dynamic twist.

## Project Overview

After a short delay, the cookie consent modal appears asking users to enter their name and email before accepting or declining.  
When users hover over the Decline button, the buttons swap positions to make it more difficult to decline.

Upon form submission, the modal simulates uploading data to the dark web and then displays a humorous thank-you message using the user's name, accompanied by a GIF animation.

## Features

- Timed modal popup using `setTimeout()`
- Button swap effect triggered on hover with `mouseenter`
- Dynamic form handling using `FormData`
- Real-time DOM updates and text replacement
- Simulated data upload sequence with timed text changes
- Personalized thank-you message displaying user input
- Simple, responsive modal design using CSS
